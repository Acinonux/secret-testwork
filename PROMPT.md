# Исходный промпт

> нужно разработать сервис для хранения и передачи секретов с шифрованием
> вот ключевые требования
>
> 1. данные шифруются в браузере клиента и отправляются на сервер уже зашифроваными
> 2. сервер не знает ключа шифрования и не может прочитать данные
> 3. ключ шифрования передается в ссылке и до сервера не доходит
> 4. после первого прочтения данные удаляются
> 5. также данные удаляются после таймаута
>
> составь подробную документацию по проекту задавай вопросы при необходимости
> стек laravel + inertia + mysql
> sail для локальной разработки
> оптимизируй работу чтобы максимально экономить токены

Уточнения в ходе диалога: Vue 3, деплой на Laravel Cloud, в MVP входят выбор TTL, загрузка файлов и подтверждение чтения.
